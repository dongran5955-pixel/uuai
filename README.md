# UUAI 视频工作台

AI 视频生成桌面软件，支持 Seedance 等模型，多张参考图锁定人物、自动封面、一键导入剪映 / Final Cut Pro。

## ⬇️ 下载

打开右侧 **[Releases（发布）](../../releases/latest)**，按你的电脑下载：

| 电脑 | 下载这个文件 |
|---|---|
| **Windows 10 / 11** | `UUAI-Workbench-版本号-Windows-Setup.exe` |
| **Mac（M1 / M2 / M3 / M4 苹果芯片）** | `UUAI-Workbench-版本号-Mac-AppleSilicon.dmg` |

## 安装

**Windows**：双击 `Setup.exe` 按提示安装。如果出现蓝色的"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行**。

**Mac**：双击 `.dmg`，把「UUAI视频工作台」拖进「应用程序」。第一次打开如提示"无法验证开发者"，到 **系统设置 → 隐私与安全性**，往下拉点 **仍要打开**。

## 使用

1. 打开软件，点左侧 **设置**
2. 在 **API Key** 里粘贴你的 Key，点 **保存连接**，再点 **测试连接**
3. 在 **视频保存位置** 里可以选择视频存到哪个文件夹

软件会自动检查更新。安装包里不包含任何 API Key，你的 Key 只保存在你自己的电脑上。
